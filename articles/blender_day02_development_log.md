## はじめに

Blender学習2日目。

前回作った机のシーンを引き継ぎ、今回は机の上に置くマグカップを制作した。

Day 1では立方体を組み合わせて机を作ったが、今回は編集モードで面や辺を直接加工した。円柱から飲み口と空洞を作り、別オブジェクトのトーラスを取っ手として組み合わせることで、少しずつ「モデリングしている感」が強くなってきた。

![Day 2の完成レンダリング](/images/blender_day02_development_log/Day02_Mug_Render.png)

## 今回の目標

- 編集モードで面と辺を扱う
- インセットと押し出しを使って、円柱を中空のカップにする
- ベベルで飲み口を滑らかにする
- トーラスを加工して取っ手を作る
- 本体と取っ手に同じ陶器マテリアルを設定する
- 完成したマグカップを机の上へ配置してレンダリングする

## Day 1のシーンを引き継ぐ

前回の `Day01_Desk.blend` を開き、Day 1の完成版を残すため、最初に別名で保存した。

```text
Day02_Mug.blend
```

机、床、ライト、カメラがすでにあるため、今回はマグカップの制作に集中できる。

## 円柱からカップ本体を作る

まずメッシュの円柱を追加し、全体を小さくしてからZ方向へ伸ばした。加工へ入る前に `Ctrl + A` からスケールを適用した。

スケールの適用は、見た目を変える操作ではない。拡大縮小後の現在の大きさを新しい基準として確定し、スケール値を `1.000` に戻す処理だった。

これを行うことで、後から使うベベルなどが残った倍率の影響を受け、不均等になるのを防げる。

> オブジェクトモードで形の比率を変え終えたら、細かな加工の前にスケールを適用する。

## インセットで飲み口を作る

`Tab`で編集モードへ入り、面選択に切り替えた。円柱の上面だけを選択し、`I`キーのインセットを使用した。

インセットによって、上面の内側にひと回り小さい面が作られる。外側に残ったリング部分が、マグカップの縁の厚みになる。

![インセット直後](/images/blender_day02_development_log/インセット直後.png)

## 押し出しで内部の空洞を作る

インセットで作った中央の面を選択したまま、下方向へ押し出してカップの内側を作った。

```text
E → -1.1 → Enter
```

ここでは最初、移動操作と同じ感覚で `E → Z → -1.1` と入力したところ、面が横方向へ飛び出してしまった。

水平な面で `E`を押すと、最初から面の法線方向、今回は上下方向へ押し出す状態になる。その後にもう一度 `Z`を押すと、すでに掛かっていた軸制限が解除され、自由移動になってしまうことが分かった。

- 通常の移動：`G → Z → 数値`
- 水平な面の押し出し：`E → 数値`

操作ミスではあったものの、移動と押し出しの挙動の違いを実際に確認できた。

![カップの空洞](/images/blender_day02_development_log/カップの空洞.png)

## ベベルで飲み口を丸める

辺選択に切り替え、`Alt + 左クリック`で飲み口の外周をループ選択した。さらに `Shift + Alt + 左クリック`で内周も追加選択した。

選択した内外2本の輪に `Ctrl + B`でベベルを加え、幅を `0.04m`、分割数を3に設定した。

これにより、飲み口の尖った直角が少し丸くなり、陶器らしい滑らかな縁になった。

本体には「自動スムーズシェード」も設定した。形状自体は変えず、円柱側面の面と面の境界を滑らかに表示できた。

## トーラスから取っ手を作る

取っ手は本体とは別のオブジェクトとして、ドーナツ形のトーラスから作った。

トーラスを90度回転して縦向きにし、縦長に変形してカップ本体の横へ配置した。本体に一部を食い込ませることで、外から見える部分をC字形の取っ手として利用している。

最初は取っ手が本体と同じくらい大きくなってしまったため、何度か縮小した。固定値で本体側へ寄せた際には埋まりすぎたので、最後は `G → X`のあとマウスを使い、見た目を確認しながら位置を調整した。

数値入力は正確だが、形同士のバランスを決める場面では、視点を動かしながら目分量で整える方が適している場合もあると分かった。

![取っ手調整後](/images/blender_day02_development_log/取っ手調整後.png)

## 陶器マテリアルを設定する

本体に `Ceramic`というマテリアルを作り、深い青色を設定した。粗さは `0.3`にして、少し光沢のある陶器らしい質感にした。

取っ手も同じ質感にするため、本体と取っ手を選択して `Ctrl + L`から「マテリアルをリンク」を実行した。これで両方のオブジェクトが同じ `Ceramic`マテリアルを共有するようになった。

## 本体と取っ手を結合する

マグカップ全体を一緒に移動できるよう、本体と取っ手を選択し、`Ctrl + J`で1つのオブジェクトへ結合した。

このとき、結合後の名前は最後に選択したアクティブオブジェクトの名前が残る。今回は取っ手側がアクティブだったため、結合後の名前が `Mug_Handle`になった。

形が消えたわけではないので、今回は `F2`で `Mug`へ変更した。今後は残したい側のオブジェクトを最後に選択してから結合すればよい。

## 机の上へ配置する

結合したマグカップを、`G → Z`で天板の高さまで上げた。その後、X軸とY軸方向へ移動し、机の上の好きな位置へ配置した。

ここでも視点を回しながら、底が天板へ埋まりすぎず、宙にも浮かない位置を目分量で探した。

## カメラを調整してレンダリングする

マグカップを追加したことで、Day 1のカメラ構図を調整する必要があった。

今回はカメラ視点でNパネルの「カメラをビューにロック」を有効にした。普段の視点操作と同じ感覚でカメラを動かせるため、数値で調整するより構図を決めやすかった。

- ホイール：寄る・引く
- `Shift + 中ボタンドラッグ`：上下左右へ平行移動
- 中ボタンドラッグ：角度を変更

机、4本の脚、床、マグカップがすべて収まる画角にしてレンダリングした。構図決定後は、意図せずカメラを動かさないよう「カメラをビューにロック」を解除した。

## 今日使った主な操作

| 操作                       | 内容                                     |
| -------------------------- | ---------------------------------------- |
| `Tab`                      | オブジェクトモードと編集モードの切り替え |
| `1` / `2` / `3`            | 頂点・辺・面選択への切り替え             |
| `I`                        | 面をインセットする                       |
| `E`                        | 選択した面を押し出す                     |
| `Alt + 左クリック`         | 辺ループを選択する                       |
| `Shift + Alt + 左クリック` | 辺ループを追加選択する                   |
| `Ctrl + B`                 | 選択した辺をベベルする                   |
| `Ctrl + A`                 | スケールなどを適用する                   |
| `Shift + S`                | 3Dカーソル関連のメニューを開く           |
| `Ctrl + L`                 | マテリアルなどをリンクする               |
| `Ctrl + J`                 | 複数オブジェクトを結合する               |
| `F2`                       | オブジェクト名を変更する                 |
| `テンキー0`                | カメラ視点へ切り替える                   |
| `F12`                      | レンダリングする                         |

## 振り返り

Day 2では、単純なオブジェクトの配置から一歩進み、円柱の面と辺を加工してマグカップを作れた。

特に印象に残ったのは、操作を間違えたことで `E`による押し出しの軸制限を理解できたこと。また、取っ手の大きさや位置、机への配置では、数値だけに頼らず自分で見た目を判断しながら調整できた。

まだショートカットをすべて覚えているわけではないが、繰り返し使う操作は少しずつ見覚えが出てきた。短時間でも毎日触り、作品を1つずつ育てていく形なら、趣味として無理なく続けられそうだ。
