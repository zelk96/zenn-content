## はじめに

今日からBlenderを使った3DCGの学習を始めました。

これまで3DCGにはほとんど触れたことがなく、Blenderのインストールから始める完全な初心者です。最初は自分のPCで動くのか少し不安でしたが、無事に起動でき、初日の課題として簡単な机を完成させるところまで進められました。

今回は細かな操作をすべて暗記することよりも、**モデリングからレンダリングまでの一連の流れを体験すること**を目標にしました。

## 使用環境

- Blender 5.2.0
- Windows
- CPU：Intel Core i7-8700
- GPU：NVIDIA GeForce GTX 1660 Ti（VRAM 6GB）
- メモリ：16GB

Blender公式の推奨スペックには届いていない部分もありますが、今回のような基礎学習では特に問題なく作業できました。最終レンダリングも1秒未満で完了しています。

## 今日作ったもの

初日の課題として、立方体を組み合わせたシンプルな机を作りました。

![完成レンダリング画像](/images/blender_day01_development_log/Day01_Desk_Render.png)

完成までのおおまかな工程は次のとおりです。

1. 立方体を変形して天板を作る
2. 細長い立方体で脚を1本作る
3. 脚を複製して四隅へ配置する
4. 角をベベルで丸める
5. 木材風のマテリアルを設定する
6. 床を追加する
7. カメラとライトを調整する
8. 画像としてレンダリングする

## 基本操作を覚える

最初に、3Dビューポート内での視点操作を練習しました。

- マウスホイール：拡大・縮小
- ホイールを押しながら移動：視点の回転
- `Shift + ホイール押し込み`：視点の平行移動
- テンキーの `1`：正面表示
- テンキーの `0`：カメラ視点

続いて、オブジェクトを変形する3つの基本操作を試しました。

- `G`：移動
- `R`：回転
- `S`：拡大・縮小

操作のあとに `X`、`Y`、`Z`を押すと、変形する方向を特定の軸に固定できます。たとえば `G` → `Z` と入力すると、オブジェクトを上下方向だけに動かせます。

## 机のモデリング

最初から配置されている立方体をX・Y方向へ伸ばし、Z方向へ薄くして天板を作りました。

脚は新しい立方体を追加して細長く変形し、天板の角へ移動。その脚を `Shift + D` で複製して、合計4本にしました。

この作業を通して、数値を入力して正確に変形・配置する方法と、既存のオブジェクトを複製して効率よく作る方法を体験できました。

![モデリング途中](/images/blender_day01_development_log/モデリング途中.png)

## スケールの適用とベベル

天板と脚を作った直後は、オブジェクトに拡大・縮小の倍率が残っています。そこで `Ctrl + A` から「スケール」を適用し、現在の形を基準の状態にしました。

その後、編集モードで全頂点を選択し、`Ctrl + B` のベベルを使って角を少し丸めました。

直方体を並べただけの状態と比べると、わずかに角を丸めるだけでも見た目がかなり自然になります。単純な形状でも、こうした小さな加工が質感に影響することを実感しました。

## オブジェクト名の整理

作成したパーツには、次のような名前を付けました。

- `Desk_Top`
- `Desk_Leg_01`
- `Desk_Leg_02`
- `Desk_Leg_03`
- `Desk_Leg_04`
- `Floor`

今回は数個のオブジェクトしかありませんが、今後モデルが複雑になったときに迷わないよう、最初から名前を整理する習慣を付けていきます。

## マテリアルと床の設定

机には `Wood` というマテリアルを作り、茶色のベースカラーを設定しました。作成したマテリアルを天板と4本の脚へリンクし、すべてのパーツで共有しています。

さらに平面を追加して床を作り、机とは別の `Floor_Material` を設定しました。床には暗めのグレーを選び、粗さを `0.8` にしています。

マテリアルプレビューへ切り替えた瞬間、白いモデルだった机に色が付き、一気に作品らしく見えたのが印象的でした。

![マテリアル設定後](/images/blender_day01_development_log/マテリアル設定後.png)

## カメラ・ライト・レンダリング

ビューポートで構図を決めたあと、`Ctrl + Alt + テンキー0` で現在の視点にカメラを合わせました。

最初のレンダリングでは、初期状態のポイントライトを使用しました。レンダリング自体は成功したものの、影が強く、机の一部が暗く見える結果になりました。

そこでライトを「エリア」へ変更し、次のように調整しました。

- パワー：1000W
- 形状：長方形
- サイズX：5m
- サイズY：5m

再レンダリングすると影の境界が柔らかくなり、暗い部分にも自然に光が回るようになりました。同じモデルでも、ライトの種類や大きさによって印象が大きく変わることが分かりました。

![調整後レンダリング](/images/blender_day01_development_log/調整後レンダリング.png)

## 今日覚えた主なショートカット

初日から多くのショートカットが登場しましたが、現時点ではすべて暗記しようとせず、特によく使ったものを中心に整理します。

| キー            | 操作                                     |
| --------------- | ---------------------------------------- |
| `G`             | 移動                                     |
| `R`             | 回転                                     |
| `S`             | 拡大・縮小                               |
| `X` / `Y` / `Z` | 操作する軸を固定                         |
| `Shift + A`     | オブジェクトを追加                       |
| `Shift + D`     | オブジェクトを複製                       |
| `Tab`           | オブジェクトモードと編集モードの切り替え |
| `Ctrl + A`      | トランスフォームを適用                   |
| `Ctrl + B`      | ベベル                                   |
| `F2`            | 名前を変更                               |
| `F12`           | レンダリング                             |

## 感想

ショートカットが多く、最初からすべて覚えるのは大変そうだと感じました。ただ、実際に手を動かしてみると、移動・回転・拡大縮小などの基本操作は何度も使うため、制作を続けるうちに自然と身に付きそうです。

何より、初日から自分で作ったモデルに色を付け、ライトを当て、1枚の画像として完成させるところまで体験できたのが楽しかったです。

3DCGは技術習得のためだけではなく、趣味としても続けられそうだと感じました。
